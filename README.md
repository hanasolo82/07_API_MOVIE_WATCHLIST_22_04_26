# 🎬 Movie Watchlist App

## 📌 Requirements

### 1. Pages
- The project must include **two pages**:
  - `index.html`
  - `watchlist.html`

---

### 2. Search Page (`index.html`)
- Acts as the **main search interface**.
- Makes requests to the **OMDB API** using the movie title entered by the user.
- Displays the **search results dynamically**.

---

### 3. Watchlist Feature
- Each movie result must include a button:
  - ➕ **"Add to Watchlist"**
- When clicked:
  - The selected movie data is stored in **Local Storage**.

---

### 4. Watchlist Page (`watchlist.html`)
- Loads and displays movies saved in **Local Storage**.
- Shows the user’s saved watchlist.

---

## 💡 Optional Improvements
- Prevent duplicate movies in the watchlist.
- Add a remove button (❌) to delete movies from the watchlist.
- Display a message when the watchlist is empty.

---

## 🛠️ Technologies
- HTML
- CSS
- JavaScript
- OMDB API
- Local Storage
